Choose the adapter that owns your application's development pipeline. The desktop manager detects the installed adapter when you open the project.

## Vite

### Install the project packages

Add the authoring API and Vite plugin to the project whose components you want to explore:

```bash
pnpm add -D @gobrand/openstory-config @gobrand/openstory-vite
```

The browser runtime is installed transitively by `@gobrand/openstory-vite`; you do not need to manage it separately.

OpenStory currently supports Vite 7 and 8. Your project also needs React 19.

### Add the Vite plugin

Add `openStory()` before framework and runtime adapters in `vite.config.ts`:

```ts
import { cloudflare } from "@cloudflare/vite-plugin";
import react from "@vitejs/plugin-react";
import { openStory } from "@gobrand/openstory-vite";
import { tanstackStart } from "@tanstack/react-start/plugin/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [react(), openStory(), tanstackStart(), cloudflare()],
});
```

OpenStory starts Vite with `mode: "openstory"`. In that mode it automatically isolates the preview harness from supported pipeline owners such as TanStack Start and `@cloudflare/vite-plugin`, while normal development and builds remain unchanged. TanStack Start is a framework plugin; Cloudflare is a platform/runtime and its Vite package is a runtime adapter.

Unknown plugins stay enabled. If an unsupported adapter conflicts, use its exact Vite plugin name as an advanced escape hatch:

```ts
openStory({
  compatibility: {
    disable: ["my-runtime:dev-server"],
    keep: ["my-runtime:diagnostics"],
  },
});
```

`keep` takes precedence over built-in and custom disabling.

## Next.js

For a Next.js 16 App Router project using Turbopack, install the authoring API and Next adapter:

```bash
pnpm add -D @gobrand/openstory-config @gobrand/openstory-next
```

There is no `next.config` wrapper and no route to add. Open the project in the desktop manager, or run the adapter directly:

```json
{
  "scripts": {
    "story:dev": "openstory-next"
  }
}
```

The adapter generates a disposable App Router application under `.openstory/cache`, then runs it with the project's installed Next.js and Turbopack. Add `.openstory/` to the project's ignore file.

The repository requires Node.js 22 or newer:

```bash
git clone https://github.com/go-brand/openstory.git
cd openstory
corepack enable
pnpm install
pnpm dev
```

The development command builds the packages and opens the Electron manager.
